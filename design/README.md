# Approved design materials

The approved StationSnap mobile workflow handoff is stored in
`stationsnap-mobile-workflows/`.

Primary references:

- `StationSnap.dc.html` — interactive high-fidelity canvas containing 20 screens
- `README.md` — screen-by-screen visual and interaction specification
- `nocturne/styles.css` — approved color, type, spacing, radius, elevation, and component tokens
- `api-contract.md` and `data-shapes.js` — prototype data requirements that must be reconciled with the product roadmap and production security model

The handoff is the visual source of truth. Its prototype code is reference material, not production code to copy. Product security and authorization requirements remain authoritative where prototype behavior conflicts with the approved build phases.

Future approved materials should include:

- Editable design source files or exported specifications
- Desktop and mobile screen exports
- Component and interaction states
- Typography, color, spacing, and icon references
- Loading, empty, validation, success, and error states

Origin: `StationSnap Mobile Workflows.zip`, supplied by the project owner on 2026-08-02.
